## Applied data science capstone

**[Music Genre Classification & Audio Analytics](https://github.com/Jdevonish25/Capstone_FMA_Project)** explores genre prediction using the Free Music Archive dataset, comparing structured-data, audio and hybrid approaches. The repository includes notebooks, model artifacts, reports and final evaluation outputs.

[Try the Streamlit demo](https://capstone-fma-genre-demo.streamlit.app/) · [Read the project documentation](https://github.com/Jdevonish25/Capstone_FMA_Project/tree/main/documentation)

The project presents ranked genre suggestions and discusses the limits of external-song generalization; it is a research demonstration rather than a production music-labeling service.
