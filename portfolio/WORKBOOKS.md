# Working with the Tableau workbooks

Use the live Tableau Public links in this folder’s README for browser-based exploration. The six `.twbx` files are the final packaged portfolio workbooks, including their embedded data extracts and viewer guides.

To inspect calculations, sheets and dashboard layout, download a workbook and open it in a compatible Tableau application. Begin with **00 | Start Here** for data definitions, navigation and limitations. These files are historical snapshots; published sources may later be revised.

The portfolio combines public-source, historical, sample and synthetic datasets. Read each case study before interpreting its metrics.
